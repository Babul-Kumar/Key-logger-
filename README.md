Educational Keylogger Simulator
Disclaimer: This project is developed strictly for educational purposes to demonstrate cybersecurity concepts in a controlled environment. It is not intended for unauthorized monitoring, data collection, or malicious activities.
Overview
The Educational Keylogger Simulator is a cybersecurity learning project designed to help students understand the concepts behind keyboard event monitoring, system security, malware analysis, and defensive cybersecurity practices.
Rather than being a tool for misuse, this project focuses on explaining how such software operates conceptually and how security professionals detect and defend against it.
Features
Interactive educational interface
Simulated monitoring session
Session start and stop controls
Timestamped demonstration events
Session summary
Log viewer
Export demonstration logs
Clear logs option
Educational explanations
Simple and lightweight GUI
Objectives
Learn how keyboard input is processed by operating systems.
Understand the behavior of monitoring software.

Installation
Clone the repository.
git clone https://github.com/yourusername/educational-keylogger.git
Open the project folder.
cd educational-keylogger
Install the required dependencies.
pip install -r requirements.txt
Run the application.
python main.py
How It Works
Launch the application.
Read the educational disclaimer.
Start a demonstration session.
Observe simulated events and session information.
Stop the session.
Review or export the generated demonstration log.
Exit the application.
